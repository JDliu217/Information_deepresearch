# 消费者权益 RAG 权威资料集（第一批）

本资料集面向**中国大陆消费者权益保护**第一版 RAG。它收录现行核心法律、行政法规、司法解释，以及一份线上购物七日无理由退货规章文本。原始官方文件保存在 `raw/`，按条切分后的检索文本保存在 `processed/`。

## 当前内容

- 10 份官方文本，合计 1,851 条条文记录。
- 9 份法律、行政法规或司法解释来自全国人大国家法律法规数据库；该库记录的状态码均为 `3`（有效）。
- 1 份《网络购买商品七日无理由退货暂行办法》来自国务院官网镜像。镜像正文注明该办法于 2017 年发布，并依据市场监管总局令第 31 号于 2020 年修正。此文保留为补充语料；当前资料集没有给它标注全国人大数据库的状态码。
- 《民法典》按完整法律收入，不只抽取消费者合同相关条文。检索时可通过 `document_id`、`document_title`、`chapter_title` 过滤或加权。
- 每个条文记录保留法律名称、发布机关、公布和施行日期、状态来源与状态核验日期、章节、原文、来源链接、原件相对路径、原件 SHA-256 和下载日期。

## 文件结构

```text
consumer-rights-rag-dataset/
  README.md
  build_dataset.py
  manifest.csv
  quality_report.json
  raw/
    npc_*.docx
    gov_*.html
  processed/
    articles.jsonl
    *.md
```

- `raw/`：下载的官方 DOCX 或官方网页 HTML 原件，不做内容改写。
- `processed/articles.jsonl`：推荐导入 RAG 的数据。每行一条完整法条，`text` 是检索正文，其余字段是来源与版本元数据。
- `processed/*.md`：按法条整理的可读文本，含版本信息、官方来源和原件哈希。
- `manifest.csv`：文档级来源、日期、状态、文件大小、哈希和条数。Excel 可直接打开。
- `quality_report.json`：按文档统计原文段落数和切分条数。
- `build_dataset.py`：重建数据集的下载与切分脚本。

## 导入建议

1. 读取 `processed/articles.jsonl`，每行解析为一个 JSON 对象。
2. 将 `text` 作为检索正文；将 `document_title`、`document_type`、`issuer`、`effective_date`、`legal_status`、`chapter_title`、`article_label`、`source_url`、`verification_url` 作为元数据。
3. 以 `chunk_id` 作为稳定的条文 ID，以 `document_id` 作为文档过滤键。
4. 答复中引用具体条款时，输出法律名称、条号和 `source_url`；不要只输出模型生成的摘要。
5. 入库前可以再按具体用户场景增加元数据筛选，例如线上交易、食品、预付式消费或广告，但不要删去条文来源字段。

该语料尚未接入项目的向量库或检索链路；本目录交付的是可复核、可导入的首批数据文件。

## 重建与校验

需要 Python 3.10 或更新版本以及 `requests`：

```powershell
python -m pip install requests
python .\build_dataset.py
```

脚本直接访问全国人大数据库下载接口和国务院官网镜像，不需要 API key。全国人大签名下载链接有时效性，脚本会在运行时重新申请。

本次校验结果见 `quality_report.json`：所有文件都成功读取；切分出的条文非空；各文件的条号从首条到末条连续且无重复。

脚本按已核验的数据库编号下载固定版本。再次运行会更新原件和 `retrieved_at`，但不会自动向数据库重新核验法律状态；`legal_status_checked_at` 表示目前这次状态核验的日期。若后续版本变动，需要重新核验状态和版本日期后再更新这些字段。

## 范围和局限

这是一套**消费者权益第一批实验语料**，不是中国法律的完整汇编，也不构成法律意见。它暂未覆盖地方性法规、行业标准、各类产品专项规章、金融保险与旅游教育等行业规则、投诉处理和诉讼程序的全部文件。回答具体问题时仍需要按时间、地域、交易主体和证据核对适用法律；数据库状态及规章修订应定期重新核验。

尤其是《网络购买商品七日无理由退货暂行办法》，本资料集保存的是国务院官网镜像文本及市场监管总局官方原文页面链接，`manifest.csv` 明确标示其未取得全国人大数据库状态码；把它作为检索语料，不代表自动证明其在任一具体案件中的适用性。
